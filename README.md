# Personal Developer Portfolio

A professional portfolio website for a frontend developer and BCA student. Built with HTML, CSS, and JavaScript — no frameworks required.

## Sections

- **Hero**: Introduction with availability status and key stats
- **About**: Background, skills context, and links
- **Skills**: Technical skills with project evidence backing each claim
- **Featured Projects**: Top 4 projects (NOVAE, DocuForge, Restaurant, Salon)
- **All Demos**: Links to the full 29-demo collection
- **Contact**: Contact information and what I am looking for

## Customization

Before publishing, update these placeholders in `index.html`:

| Placeholder | Replace With |
|---|---|
| `Your Name` | Your actual name |
| `NextGen-Studio1` | Your GitHub username |
| `your.email@example.com` | Your email address |
| `YOUR_LINKEDIN` | Your LinkedIn username |
| `+91XXXXXXXXXX` | Your phone number |
| `YOUR_NOVAE_DEMO_LINK` | GitHub Pages URL for NOVAE |
| `YOUR_RESTAURANT_DEMO_LINK` | GitHub Pages URL for restaurant |
| `YOUR_SALON_DEMO_LINK` | GitHub Pages URL for salon |
| `YOUR_DOCUFORGE_DEPLOY_LINK` | Railway/Render URL for DocuForge |
| `YOUR_RESUME_LINK` | Google Drive or direct link to resume |

In `style.css`, update `.about-avatar` text from `YN` to your initials.

## Local Setup

```bash
# Open directly in browser
# Double-click index.html

# Or use a local server
npx serve .
```

## Deployment (GitHub Pages)

1. Push this folder to a GitHub repository named `YOUR_USERNAME.github.io` or `portfolio`
2. If using `YOUR_USERNAME.github.io` as the repo name, GitHub automatically serves it at `https://YOUR_USERNAME.github.io`
3. If using any other name, enable Pages in Settings > Pages
